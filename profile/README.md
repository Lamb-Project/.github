The LAMB project stands for Learning Assistants/Agents Manager and Builder. 

LAMB is a web platform that allows you to design, train and publish AI-based learning assistants in a visual and intuitive way. It works as a “teaching chatbot builder” that combines language models (GPT-4o, Mistral, local models) with your own educational materials.

LAMB is an open source project developed by Marc Alier and Juanan Pereira, professors and researchers at the Universitat Politècnica de Catalunya (UPC) and Universidad del País Vasco (UPV/EHU).

Our main site is at [https://lamb-project.org]
